# Ashish K Sharma — Portfolio Website

A responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `styles.css` — complete styling and responsive layout
- `script.js` — mobile navigation, reveal animations and active-section navigation
- `favicon.svg` — simple AKS favicon

## Run locally

The site works by opening `index.html` directly in your browser.

For a better local-development workflow, use VS Code with the Live Server extension:

1. Open this folder in VS Code.
2. Right-click `index.html`.
3. Choose **Open with Live Server**.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `ashish-portfolio`.
2. Upload the files in this folder.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

GitHub will provide a public `github.io` URL after the deployment is created.

## Recommended edits before publishing
